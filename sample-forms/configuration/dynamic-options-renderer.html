Dynamic Options Renderer

Each option is a saved submission from the database, rendered as a single-select. It carries its own formConfig and a values map. Pick one to render its form prefilled from those values.

value from DB submission repository child / cap empty (not submitted)
How a value resolves. Each entry in values is keyed by formKey-fieldKey. So a field renders its value by looking up FO_BOC_INFO-FI_NAME — the field's own formKey joined to its fieldKey. Fields with no matching key render empty. Every option here ships the same FO_BOC_INFO config; only the values differ.
